# 📚 ReadHub: Peer Lending Library Web Portal

**Tired of limited access to academic resources?** **ReadHub** is a centralized web-based platform that enables students to lend and borrow academic materials within their campus community. It promotes collaboration, sharing, and sustainable access to learning tools.

| 📚 **Course** | **IT342-G01** |
| :--- | :--- |

---

## 🚀 Core Features & Benefits

ReadHub transforms traditional resource sharing into a seamless digital experience for students, contributors, and administrators.

| Feature               | Description                                                       | Benefit                                                                 |
| :--------------------|:------------------------------------------------------------------|:------------------------------------------------------------------------|
| **Peer Lending System** | Students can list and borrow academic materials from peers.         | Encourages collaboration and reduces resource gaps.                     |
| **Curated Book Listings** | Featured items and descriptions embedded in landing pages.         | Improves discoverability and promotes high-demand resources.            |
| **Borrower Dashboard** | Personalized dashboard for tracking borrowed and lent items.       | Enhances transparency and user control.                                |
| **Event & Resource Pages** | Modular pages for academic events and shared materials.            | Supports scalable and maintainable content delivery.                   |
| **Authentication & Validation** | Secure login and form validation for all user actions.         | Ensures data integrity and user accountability.                         |

---

## 💡 How ReadHub Works

1. **List or Request a Resource:** Students can post academic materials they’re willing to lend or browse available items.
2. **Borrow & Track:** Borrowers request items and track status via their dashboard.
3. **Manage & Moderate:** Admins and contributors manage listings, featured items, and event pages.

## 🏗️ Technical Architecture (The Stack)

ReadHub is built for modularity, maintainability, and collaborative development using the following technologies:

| **Layer**     | **Technology**                      |
| :------------| :----------------------------------- |
| **Frontend**  | HTML, CSS, JavaScript (React)        |
| **Backend**   | Node.js with Express.js              |
| **Database**  | MySQL                                |
| **Versioning**| Git & GitHub                         |
| **Deployment**| Vite (Frontend) + Node (Backend)     |
